# 🏎️ Wolleyder – Supercar Interactive UI

> A high-performance, animated supercar showcase UI with dynamic theming, smooth car transitions, and a sleek dark aesthetic.

---

## 📌 Project Overview

 A front-end supercar showcase interface featuring dynamic per-car color theming, animated car transitions, live stats, and an interactive selector — all built with pure **HTML, CSS, and Vanilla JavaScript**. No frameworks. No dependencies.

## ✨ Features

- 🎨 **Dynamic Per-Car Theming** — CSS variables update in real-time per selected car (color, glow, background)
- 🚗 **Smooth Car Transitions** — Slide-in/out animations with flash overlay effect
- 🔢 **Live Stats Panel** — 0–100 time, top speed, and horsepower update per car
- 🟠 **Animated Dot & Selector Bar** — Active car highlighted with color-matched indicator
- ⌨️ **Keyboard Navigation** — Arrow keys to switch between cars
- 🌑 **Dark Atmospheric UI** — Radial glow, noise texture, and dashed rotating ring deco
- 💫 **Floating Car Animation** — CSS keyframe float effect on car image
- 📱 **Responsive Design** — Adapts to mobile and tablet layouts

---

## 🎨 Design Highlights

- **Font Pairing** — `Orbitron` (headings) + `Rajdhani` (body) for a futuristic racing aesthetic
- **Color System** — Each car has its own `--primary`, `--glow`, `--bg`, and `--accent` CSS variable set
- **Background FX** — Radial gradient glow + SVG noise texture overlay for cinematic depth
- **Geometry** — Three layered decorative rings (solid, solid, dashed + rotating) around the car
